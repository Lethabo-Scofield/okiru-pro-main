Update the Okiru `.pro` website and admin dashboard to add Google Analytics tracking and a protected traffic analytics page.

## Main objectives

1. Add the Google Analytics 4 tracking tag to the public `okiru.pro` website.
2. Add a new protected Admin Analytics page.
3. Display Google Analytics traffic data inside the admin dashboard.
4. Display Google Search Console performance data where credentials and API access are available.
5. Follow the project’s existing design system, routing structure, authentication, components, and backend architecture.

Do not redesign the website or admin dashboard. Match the current UI exactly.

---

## 1. Add the Google Analytics tag

Add this Google Analytics tag once in the global document `<head>` used by the public website:

```html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-WF69VTV757"></script>
<script>
  window.dataLayer = window.dataLayer || [];

  function gtag() {
    dataLayer.push(arguments);
  }

  gtag('js', new Date());
  gtag('config', 'G-WF69VTV757');
</script>
```

The measurement ID is:

```text
G-WF69VTV757
```

Implementation requirements:

* Inspect the project framework before making changes.
* Add the tag to the correct global root layout, document, HTML template, or metadata component.
* The tag must load on all public `okiru.pro` pages.
* Do not manually duplicate it across individual pages when a shared layout exists.
* Do not add it multiple times.
* Do not add the tag to API routes, server-only files, email templates, PDF templates, or unrelated applications.
* Ensure it works correctly during client-side route changes.
* Preserve the existing page metadata, SEO tags, favicons, scripts, and styles.
* Do not replace the existing `<head>` implementation.

If the framework supports a dedicated script component, use the framework-supported implementation rather than injecting unsafe raw HTML unnecessarily.

## 3. Analytics page layout

Follow the existing Okiru admin design language, spacing, typography, cards, tables, tabs, loading states, borders, colours and responsive behaviour.

Do not introduce a new visual style.

### Date selector

Add a date-range selector with:

* Today
* Last 7 days
* Last 30 days
* Last 90 days

Default to:

```text
Last 30 days
```

* Total users
* New users
* Sessions
* Page views
* Average engagement time
* Bounce rate or engagement rate

Each card should contain:

* Metric name
* Current value
* Percentage change compared with the previous equivalent period
* Loading skeleton
* Clear empty state when no data exists

### Real-time section

Display:

* Active users in the last 30 minutes
* Top currently active pages
* Active users by country, when available

Do not refresh the entire page.

### Traffic sources

* Organic Search
* Direct
* Referral
* Organic Social
* Paid Search
* Email
* Other available channels

Columns:

* Channel
* Users
* Sessions
* Percentage of total traffic

### Top pages

Display:

* Page title

* Views
* Users
* Average engagement time

Add search and pagination when the number of rows is large.

### Audience

Display:

* Country

## 5. Environment variables

Add support for these server-side environment variables:

```env
GOOGLE_ANALYTICS_PROPERTY_ID=
GOOGLE_SERVICE_ACCOUNT_EMAIL=
GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY=
GOOGLE_SEARCH_CONSOLE_PROPERTY=sc-domain:okiru.pro
```

The GA4 numeric Property ID is different from the measurement ID.

Do not use `G-WF69VTV757` as the Analytics Property ID.

The existing measurement ID should only be used for the website tracking tag.

Handle escaped newlines in the private key correctly, for example:

```ts
process.env.GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY?.replace(/\\n/g, '\n')
```

Never expose these variables to frontend code.

Do not prefix them with public-client environment variable prefixes.

Update the project’s example environment file, but do not add real credentials to source control.

Example:

```env
GOOGLE_ANALYTICS_PROPERTY_ID=YOUR_NUMERIC_GA4_PROPERTY_ID
GOOGLE_SERVICE_ACCOUNT_EMAIL=YOUR_SERVICE_ACCOUNT_EMAIL
GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY="YOUR_PRIVATE_KEY"
GOOGLE_SEARCH_CONSOLE_PROPERTY=sc-domain:okiru.pro
```
