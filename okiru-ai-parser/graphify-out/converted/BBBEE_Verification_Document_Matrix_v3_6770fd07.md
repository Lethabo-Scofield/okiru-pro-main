| Section 1 — Methodology & The Exclusion Test (read before completing Section 2) |  |  |  |  |  |  |  |  |  |  |
| The methodology |  |  |  |  |  |  |  |  |  |  |
| TMPS is built by starting with everything and removing only what cannot defensibly remain. Step 1: include all expense and capital spend lines from the trial balance (the Inclusions column). Step 2: identify, line by line, any portion that can be excluded because the counterparty cannot reasonably hold a B-BBEE certificate (the Exclusions column). Step 3: TMPS = Inclusions − Exclusions. The objective is to get TMPS as close as possible to the actual procurement spend per the AP supplier listing — accepted variance is 5%. |  |  |  |  |  |  |  |  |  |  |
| The core exclusion principle |  |  |  |  |  |  |  |  |  |  |
| An amount is excluded from TMPS only if a B-BBEE certificate cannot reasonably be expected from the counterparty. There is no exhaustive list of exclusions — every line item must be assessed against this principle and the four supporting tests below. When in doubt, do not exclude. The burden of proof is on the exclusion. |  |  |  |  |  |  |  |  |  |  |
| The four exclusion tests |  |  |  |  |  |  |  |  |  |  |
| Exclude an amount if ANY of these four tests is met for that amount:
   1. STATUTORY — counterparty is the State, a public entity, a tax authority or any body that does not issue B-BBEE certificates (e.g. SARS, municipalities, parastatals, foreign tax authorities, SARB).
   2. EMPLOYMENT — the amount represents the cost of internal labour, not procurement (salaries, wages, bonuses, leave pay, pension and medical aid contributions forming part of remuneration, employee training).
   3. FOREIGN / NON-CERTIFIABLE — counterparty is a foreign entity with no SA operations, OR the amount is for an import meeting Code 400 Annexure 400(A) exclusion criteria (no local production AND promotes further SA value-added production, OR different brand / specification subject to a documented ESD plan).
   4. NON-PROCUREMENT — the amount is an accounting entry rather than a procurement of goods or services (depreciation, amortisation, impairment, fair-value adjustments, provisions movements, dividends, equity-settled share-based payments).
Where none of these four tests is met, the full line stays in TMPS, regardless of supplier B-BBEE status. A non-compliant supplier is still part of TMPS; their spend simply attracts a 0% recognition factor at the procurement-score step. |  |  |  |  |  |  |  |  |  |  |
| Partial exclusions |  |  |  |  |  |  |  |  |  |  |
| A line can be partially excluded. Example: a single 'Inter-entity charges' GL line of R12m may include R4m to a foreign group entity (excludable) and R8m to a domestic group entity (not excludable). Capture the full R12m in Inclusions and R4m in Exclusions; TMPS impact is R8m. The rationale must explain the split and reference the supporting workings. |  |  |  |  |  |  |  |  |  |  |
| Common judgement points |  |  |  |  |  |  |  |  |  |  |
| • Inter-entity / intra-group charges — excluded ONLY where the counterparty cannot hold a certificate (e.g. foreign group entity). Domestic intra-group spend stays in TMPS.
• Trade and broker commissions — kept in TMPS where paid to a third-party broker; excluded only where they represent pass-through to a non-certifiable counterparty.
• Public utilities (Eskom, Rand Water, municipalities) — excluded (Statutory test).
• Pension and medical aid contributions — excluded as Employment cost where part of the employee's remuneration package.
• Bad debts, impairments, fair-value movements, depreciation, amortisation — excluded (Non-procurement test).
• Bank charges — kept in TMPS where the bank can provide a B-BBEE certificate; excluded for SARB and foreign-bank fees.
• Empowerment-related procurement already counted under Code 400 — excluded to prevent double counting.
• Imports — excluded only with documented Annexure 400(A) basis. Imports for which a local equivalent exists stay in TMPS. |  |  |  |  |  |  |  |  |  |  |
| Procedural rules |  |  |  |  |  |  |  |  |  |  |
| • All amounts VAT-exclusive throughout. Strip VAT from any line captured inclusive.
• Measurement-Period basis — recognise costs incurred (goods / services delivered) within the period. Cut-off testing applies at both ends.
• Prior-year comparative — populate the prior-year columns on the same basis as the current year. Reasonability variance against the supplier listing is 5%; year-on-year movement is reviewed at 10% for business-reason commentary.
• Every exclusion must carry: a basis, a rationale applying the principle, and a supporting evidence reference. Lines with an exclusion but no rationale or evidence cannot withstand verification challenge. |  |  |  |  |  |  |  |  |  |  |
| Section 2 — Trial Balance Inclusions + Exclusion Adjustments (one row per GL line) |  |  |  |  |  |  |  |  |  |  |

Then in the Exclusion columns, record only the portion that can defensibly be removed (apply the four-test principle from Section 1). Where there is no exclusion, leave Exclusion columns blank. Where there is a partial exclusion, capture only the excluded amount. TMPS impact (column I) auto-calculates as Inclusion − Exclusion. Rationale and Evidence are mandatory for any non-zero exclusion. |  |  |  |  |  |  |  |  |  |  |
